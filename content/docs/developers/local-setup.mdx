Clone two repos side by side. In this workspace that is `klovy-chat-frontend` and `klovy-chat-backend`. Relative paths (`../backend`) in frontend scripts assume that layout, not a monorepo. Put the backend deeper or rename the folder and `npm run dev:all` will not find `cargo` — you will debug Vite instead of the path.

Desktop (`application`) is not needed for chat in the browser. Add it when you test the badge or installer.

| Tool | Version |
| --- | --- |
| Node.js | 18+ for frontend; these docs need 22+ |
| Bun or npm | frontend `package.json` pins `bun@1.2.15` |
| Rust (stable) | rustup, no nightly toolchain |
| MongoDB Atlas | connection string in `MONGODB_URI` |
| Docker | only if you run ClamAV (`scan`) |

In `development` you can skip Turnstile and ClamAV. Dummy `R2_*` values are enough for the Rust process to start. File upload on dummy config will not persist anything useful — for attachment tests you need a real bucket or a mock, which we do not ship here.

## Backend

```bash
git clone https://github.com/klovy-chat/backend.git
cd backend
cp .env.example .env
```

The only thing the template cannot guess is the Atlas URI. Everything else targets `127.0.0.1:8080`. Set `ORIGIN` and `FRONTEND_URL` to the Vite origin (`http://127.0.0.1:5173` or `http://localhost:5173` — **the same one** you use in the address bar; mixing localhost and 127.0.0.1 breaks CORS).

```bash
cargo run
```

First build takes a while. If it dies on Mongo, do not hunt for a bug in the router.

Scanner, when you actually test upload:

```bash
docker compose --profile scan up -d
```

and in `.env` `CLAMAV_HOST=127.0.0.1:3310`.

## Frontend

```bash
git clone https://github.com/klovy-chat/frontend.git
cd frontend
cp .env.example .env
```

The template has `VITE_BACKEND_URL=http://127.0.0.1:8080`. Turnstile is off in DEV; do not paste a site key "just in case".

```bash tab="Bun"
bun install
bun run dev
```

```bash tab="npm"
npm install
npm run dev
```

Client: [http://127.0.0.1:5173](http://127.0.0.1:5173). Vite proxy catches `/api`, `/whitelist`, and `/ws`, so in DEV you often never point the browser straight at `:8080`.

If the backend sits in `../backend`, one command works:

```bash
npm run dev:all
```

## Desktop

```bash
git clone https://github.com/klovy-chat/application.git
cd application
npm install
npm run dev
```

You need Rust and the OS SDK: WebView2 on Windows, Xcode on macOS, WebKitGTK 4.1 on Linux. In `dev` the window loads the frontend from the network (or from Vite, depending on config). Unread badge and updater **do not** behave like the installer build — for that you need a packaged build.

## When things break

Backend without `MONGODB_URI` will not start, full stop. CORS: `ORIGIN` / `FRONTEND_URL` ≠ what is in the browser. Port `8080` taken — change `PORT` and the same number in `VITE_BACKEND_URL`. These docs (Fumadocs) on Node below 22 throw Turbopack or `require(esm)` errors; that is not a chat frontend bug.
