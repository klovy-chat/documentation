Klucz Giphy zostaje na serwerze. Klient woła tylko nasz backend. Sesja wymagana. Nie wklejaj klucza do Vite i nie bij w api.giphy.com z przeglądarki — CORS i tak Cię wytnie, a klucz wycieknie w bundle.

GIF i naklejka to URL. Wysyłka do czatu i tak jest ramką WS z `fileUrl`, nie osobnym POST-em „wyślij gifa”.

## GIF-y — `/api/gifs`

Alias: `/api/gif`.

### GET `/api/gifs/trending`

Query: `limit` (domyślnie 24), `lang` (`pl` | `en`).

```json
{
  "gifs": [
    {
      "id": "…",
      "title": "…",
      "url": "https://…",
      "preview": "https://…",
      "width": 480,
      "height": 270
    }
  ]
}
```

Aliasy trendów: `GET /api/gifs`, `/trends`.

### GET `/api/gifs/search`

```http
GET /api/gifs/search?q=kot&limit=24&lang=pl
```

Limiter wyszukiwania (`discovery_limiter`).
