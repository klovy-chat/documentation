Prefix `/api/messages` (alias `/api/message`). Session and whitelist. You cannot send a new message here — that is WS. HTTP is for history, pins, search, and files. In the app, edit and delete also go via frames; `PUT`/`DELETE` on this prefix exist if you write your own client.

Types: `TEXT`, `FILE`, `IMAGE`, `VIDEO`, `AUDIO`, `STICKER`, `CALL`. Content max 2000 characters. On send, include `clientNonce`, otherwise a retry on a flaky socket will duplicate. Search wants `contactId` or `channelId`, not both.

## History

### POST `/api/messages/get-messages`

Aliases: `POST /api/messages`, `/list`.

DM:

```json
{
  "id": "contactUserId",
  "before": "messageId",
  "limit": 50
}
```

```json
{
  "messages": [],
  "hasMore": true
}
```

Channel history: `GET /api/channel/get-channel-messages/{channelId}?before=&limit=`.

### POST `/api/messages/pinned`

```json
{ "contactId": "…" }
```

or `{ "channelId": "…" }`.

### POST `/api/messages/search`

Min. 2 characters.

```json
{
  "query": "hasło",
  "contactId": "…",
  "channelId": "…"
}
```

Provide `contactId` **or** `channelId`.

## Mutations

### PUT `/api/messages/{messageId}`

Edit your own message. In the app this goes via the `editMessage` frame.

```json
{ "content": "nowy tekst" }
```

### DELETE `/api/messages/{messageId}`

Soft delete. In the app the `deleteMessage` frame.

### POST `/api/messages/{messageId}/pin`

### DELETE `/api/messages/{messageId}/pin`

Separate pin rate limiter.

## Files and links

### POST `/api/messages/upload-file`

Aliases: `/upload`, `/file`. `multipart/form-data`:

| Field | Value |
| --- | --- |
| `file` | file (max ~10 MB) |
| `contentType` | MIME |
| `contextType` | `dm` or `channel` |
| `contextId` | contact or channel id |

```json
{
  "filePath": "…",
  "scanStatus": "pending"
}
```

`scanStatus`: `pending` | `clean` | `blocked` (ClamAV). Blocked files do not reach the CDN.

### POST `/api/messages/link-preview`

```json
{ "url": "https://open.spotify.com/track/…" }
```

## Realtime (not REST)

| WS `type` | Role |
| --- | --- |
| `sendMessage` | new DM |
| `send-channel-message` | channel |
| `editMessage` / `deleteMessage` | mutations |
| `message-reaction` | reaction (max 20 per message) |
| `receiveMessage` / `receive-channel-message` | receive |
| `message-mention` | mention |
