There is no server above channels. People coming from Discord look for guilds, roles, and `#general` underneath — here a channel is just a group. In Mongo: name, avatar, `members`, `admin` = creator. REST: [channels API](/docs/api/channels).

`POST /api/channel/create-channel` `{ name, members }`. Creator is the only admin, period. No "second mod" or bot with kick. `POST /api/channel/add-user/{id}` `{ userIdToAdd }` is the same — client usually puts `members` in create; add-user is for adding someone later.

You join from outside via invite or add-user. No public discovery. You can't search for a channel by name from the street.

| | |
| --- | --- |
| `GET/POST /api/channel/{id}/invites` | list / `{ maxUses? }` |
| `DELETE …/invites/{inviteId}` | revoke |
| `GET /api/invite/{id}` | preview, must be logged in |
| `POST /api/invite/{id}/accept` | join |

Preview may show: missing, expired, revoked, limit hit. UI at `/invite/:id` should distinguish these, not one generic "doesn't work". `DELETE /api/channel/delete/{id}` wipes messages for good — that's not leave. After `leave` you only get back with a new invite; an old link won't let you in if it was one-time or revoked.

Kick / unban / unmute: `{ userId }`. Ban and mute-member: `{ userId, durationSeconds? }` — no duration = permanent; UI from 5 min to 7 days. Slowmode and lock: `PATCH`, not POST. Report: `{ reason, details? }` (`spam`, `offensive`, `harassment`, `illegal`, `impersonation`, `other`). `POST …/mute` is muting notifications for yourself. Muting a member is a different route (`mute-member`). Easy to confuse — both have "mute" in the name.

Voice hangs on the same channel; there is no separate voice channel. Token: `POST /api/voice/token` `{ channelId }`, frames `channel-voice:*`. Opening chat alone doesn't connect the mic — you must `join`. [Voice](/docs/product/connections).

On the list over WS: `channel-added`, `left`, `deleted`, `member-joined` / `left`, `name-updated`, `avatar-updated`, `slowmode-updated`, `chat-locked-updated`, `moderation-updated`. If you add a field on the channel and don't emit a frame, the other tab sees the change only after reload.
